# Demo Talking Points (60-90 seconds)

## Introduction (10 seconds)
"Good [morning/afternoon], judges. I'm demonstrating an AI-Generated Voice Detection system. This project shows how we can classify uploaded audio as either human or AI-generated."

## Frontend Overview (20 seconds)
"The frontend is built with simple HTML, CSS, and JavaScript. Users upload an audio file - either WAV or MP3 format. The system converts it to Base64 in the browser and sends a POST request to the backend API. The predict button is disabled until a file is selected, and there's a loading state during processing."

## Result Display (15 seconds)
"Once processed, the system displays the classification result. It shows the prediction label - Human or AI Generated - along with a confidence percentage visualized as a progress bar, and a brief explanation from the backend."

## Technical Details (15 seconds)
"The API integration is straightforward - we send the Base64 audio data and receive a JSON response with prediction, confidence, and explanation. For demo purposes, there's also a mock API mode that works even if the backend is unavailable."

## Limitations (10 seconds)
"This is a demonstration system with clear limitations. It only works with WAV and MP3 files, requires a backend server for full functionality, and accuracy depends on the underlying model. It's designed for short audio clips and may not generalize to all types of audio."

## Closing (5 seconds)
"Thank you for your time. The system is honest about its capabilities and focuses on clear, reliable user experience."

---

**Timing Notes:**
- Speak calmly and confidently
- Pause briefly between sections
- Use the UI to demonstrate as you speak
- Avoid technical jargon unless explaining a key point
- End with the limitations to show honesty
